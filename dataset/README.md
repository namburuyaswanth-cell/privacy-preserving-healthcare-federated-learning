# Dataset

The project report references the NIH Chest X-ray dataset hosted on Kaggle:

https://www.kaggle.com/datasets/nih-chest-xrays/data

The dataset is **not included in this repository**.

For the implementation code supplied in the report, the expected local structure is:

```text
dataset/
├── NORMAL/
└── PNEUMONIA/
```

The implementation reads images from these folders, resizes them to 128×128, and normalizes pixel values.

Please obtain and use the dataset according to its original terms and licensing conditions.
